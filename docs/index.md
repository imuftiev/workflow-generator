# PXF YAML Generator

Инструмент для автоматической генерации YAML-конфигураций на основе Excel-файла.

## Возможности

- Чтение списка потоков из Excel с помощью Pandas.
- Генерация Control Flow конфигураций.
- Генерация Workflow Init конфигураций.
- Генерация DB Table конфигураций.
- Использование Jinja2 для шаблонизации YAML.
- Автоматическое тестирование с помощью pytest.

## Технологии

- Python
- Pandas
- Jinja2
- Poetry
- pytest
- GitHub Actions

## Принцип работы

1. Программа читает Excel-файл с колонками `Flows` и `Schema`.
2. Обрабатывает данные потоков.
3. Подставляет значения в шаблоны Jinja2.
4. Создаёт YAML-файлы в соответствующих директориях.
